## How to sign

Add your name to `CONTRIBUTORS.md` in the same pull request as your first
contribution, using this line:

```
- Full Name <email> — GitHub @handle — agreed to CLA.md on YYYY-MM-DD
```

Opening that pull request is your signature. If you are contributing on behalf
of an employer, say so on the same line and confirm you have their authorization.
