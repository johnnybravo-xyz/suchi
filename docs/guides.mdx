Start with [Getting started](/getting-started) for installation and first-run
setup. These guides cover integrations that need additional credentials or
provider configuration.

## Archive operations

- [Restore a Suchi export](/guides/export-import) covers portable document
  takeout, fresh-instance preparation, filesystem-watch restore, and the v0.1
  metadata boundary.

## Email intake

- [Connect a mailbox](/guides/mail-intake) covers provider presets, app
  passwords, folders, filters, and troubleshooting.
- [Sign in to Microsoft or Outlook](/guides/mail-intake-oauth) covers the
  shipped device-code flow and deployment client-ID override.
- [Use the mbsync sidecar](/guides/mail-mbsync) covers the optional
  filesystem-based alternative.

## External clients

- [Connect an MCP client](/guides/mcp-connect) covers local stdio and remote
  HTTP transports.
- [Connect an external application](/guides/external-app) covers scoped API
  tokens, pagination, and uploads.

For command and payload details, use the [CLI](/cli), [API](/api), and
[configuration](/config) references. Development and verification commands
live in the repository's `CONTRIBUTING.md`.
