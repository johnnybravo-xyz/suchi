Pick the deployment shape that fits.

## Docker Compose (canonical)

```yaml docker-compose.yml
services:
  suchi:
    image: ghcr.io/johnnybravo-xyz/suchi:latest
    restart: unless-stopped
    user: "1000:1000"
    read_only: true
    tmpfs: [/tmp]
    security_opt: [no-new-privileges:true]
    cap_drop: [ALL]
    volumes:
      - ./data:/data
    ports:
      - "8000:8000"
    environment:
      PUBLIC_URL: https://docs.example.com
```

```bash
docker compose up -d
docker compose logs suchi | grep 'setup.token'
```

Copy the token from the log and POST it to `/setup`:

```bash
curl -X POST http://localhost:8000/setup \
    -H 'Content-Type: application/json' \
    -d '{"token":"<the token>","email":"you@example.com","password":"..."}'
```

Then hit `http://localhost:8000/` in a browser and sign in.

## Bare binary + systemd

Download the `suchi` binary for your OS/arch from the
[releases page](https://github.com/johnnybravo-xyz/suchi/releases).

```bash
install -m 0755 suchi /usr/local/bin/suchi
mkdir -p /var/lib/suchi
suchi serve
```

Ready-to-copy templates for the four common self-host shapes live
under [`deploy/`](https://github.com/johnnybravo-xyz/suchi/tree/main/deploy)
in the repo:

- `deploy/systemd/suchi.service` — systemd unit with a hardened
  sandbox and the two required env vars pre-set.
- `deploy/caddy/Caddyfile` — Caddy reverse-proxy block (auto-TLS).
- `deploy/nginx/suchi.conf` — nginx server block (bring your own
  certs).
- `deploy/traefik/suchi.yml` — Traefik dynamic-config snippet.
- `deploy/k8s/suchi.yaml` — single-replica Deployment + PVC + Service.
  SQLite is single-writer; do not scale up.

Every template documents the placeholders you need to edit before
paste.

## What just happened?

- On first boot, suchi ran embedded migrations up to the current
  schema version.
- It auto-loaded the Johnny.Decimal starter tree (four areas: Life
  admin, Money, Home, System). See [JD](/jd) for the shape.
- It printed a one-time setup token to the log at WARN level.
- `/healthz` is process-alive; `/readyz` is DB-reachable + schema
  current.
- `/metrics` exposes Prometheus counters (idle counts, HTTP latency
  histogram, job pipeline gauges).

## Picking an image: slim vs full

The `ghcr.io/johnnybravo-xyz/suchi:latest` tag is the **slim** image
(~70 MB, Alpine + qpdf + pdftotext + tesseract). It covers the whole
PDF pipeline including OCR of scanned pages via the in-process
`tessocr` engine (pdftoppm → tesseract). Image barcodes, EPUBs, and
office documents (docx, xlsx, pptx, odt, rtf, csv via anydoc) work
out of the box. **What it doesn't ship:** the ocrmypdf wrapper (so
no text-selectable scanned-PDF archives — the extracted text still
lands in `documents.content` and FTS indexes it), DjVu, and Outlook
`.msg` parsing.

For those, pull the **full** image (~400 MB):
`ghcr.io/johnnybravo-xyz/suchi:latest-full`. Same binary, extra runtime deps.

Both images can be forced to a specific OCR engine via `OCR_ENGINE`
(`auto` | `tesseract` | `ocrmypdf`). See [supported file types](/formats)
for the per-format matrix.

## Bare-metal tooling

If you're running the suchi binary directly (not the Docker image),
the pipeline shells out to a handful of external binaries. Missing
tools degrade features silently — the boot log emits
`main.tools.missing` for anything not on PATH, along with an install
hint per tool.

**anydoc** — office document text extraction (docx, xlsx, pptx, odt,
rtf, csv). Firecrawl publishes the source but no prebuilt binaries;
suchi's GitHub Releases attach one built from the same source as the
Docker image. One-liner install:

```sh
curl -sfL https://raw.githubusercontent.com/johnnybravo-xyz/suchi/main/hack/install-anydoc.sh | sh
```

Or, pin a specific release: `sh install-anydoc.sh --version v0.1.0`.
Dry-run mode is `--dry-run`. The script verifies SHA256 against the
release's `SHA256SUMS` before installing.

**Other tools** — install via your OS package manager. Each is a
strict dependency of one feature; suchi runs without them but the
matching pipeline degrades:

| Tool                     | Package                                                | Feature that degrades                                                     |
| ------------------------ | ------------------------------------------------------ | ------------------------------------------------------------------------- |
| `qpdf`                   | `apt install qpdf` · `brew install qpdf`               | PDF normalization + encrypted-PDF gate                                    |
| `pdftotext` + `pdftoppm` | `apt install poppler-utils` · `brew install poppler`   | text-native PDF extraction; scanned-PDF rasterization; QR-split detection |
| `tesseract`              | `apt install tesseract-ocr` · `brew install tesseract` | OCR engine for scanned PDFs (tessocr path)                                |
| `ocrmypdf`               | `apt install ocrmypdf` · `brew install ocrmypdf`       | OCR engine that produces searchable-PDF archives                          |
| `djvutxt`                | `apt install djvulibre-bin` · `brew install djvulibre` | DjVu text extraction                                                      |
| `magick` / `convert`     | `apt install imagemagick` · `brew install imagemagick` | HEIC → JPEG conversion for iPhone photos                                  |
| `msgconvert`             | `apt install libemail-outlook-message-perl`            | Outlook `.msg` → `.eml` conversion                                        |

Run `suchi doctor` for a one-shot summary of what's on PATH.
