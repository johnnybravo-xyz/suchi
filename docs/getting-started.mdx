## Docker

The standard beta image is the recommended starting point:

```sh
docker volume create suchi-data
docker run -d --name suchi --restart unless-stopped \
  --read-only --tmpfs /tmp --security-opt no-new-privileges --cap-drop ALL \
  -p 8000:8000 \
  -e PUBLIC_URL=http://127.0.0.1:8000 \
  -v suchi-data:/data \
  ghcr.io/johnnybravo-xyz/suchi:beta
docker logs suchi 2>&1 | grep token_minted
```

Open `http://127.0.0.1:8000`, enter the one-time setup token from the log, and
create the first administrator.

The setup wizard then asks what you are organizing:

| Choice | Recommended filing tree |
| --- | --- |
| Personal | Personal filing |
| Household | Household |
| Freelance | Freelance / consultant |
| Small business | Small-business billing |
| Choose myself | Full preset catalog |

The recommendation changes the default, not the available setup steps. You can
compare all filing trees, skip starter rules and automations, and change the
tree later.

## Docker Compose

The repository includes a minimal `compose.yaml`:

```sh
docker compose up -d
docker compose logs suchi | grep token_minted
```

Set `PUBLIC_URL`, `SUCHI_PORT`, or `SUCHI_IMAGE` in `.env` before starting.
Edit the volume and network definitions when integrating an existing reverse
proxy or storage layout.

## Direct binary

Download the binary for your platform from
[GitHub Releases](https://github.com/johnnybravo-xyz/suchi/releases), then run:

```sh
install -m 0755 suchi /usr/local/bin/suchi
mkdir -p "$HOME/.local/share/suchi"
PUBLIC_URL=http://127.0.0.1:8000 \
DATA_DIR="$HOME/.local/share/suchi" \
suchi serve
```

Production templates for systemd, Caddy, nginx, Traefik, Kubernetes, and the
optional mbsync helper live under
[`deploy/`](https://github.com/johnnybravo-xyz/suchi/tree/main/deploy).
Use one application replica because SQLite has one writer.

## Image choice

- `beta` is the standard Alpine image. It indexes scanned PDFs with Tesseract
  and includes the supported office, email, image, and archive extractors.
- `beta-full` adds OCRmyPDF so scanned PDF downloads can retain a searchable
  text layer.

The Suchi application is otherwise the same. See [Supported formats](/formats)
for exact routing, image sizes, and direct-install dependencies.

## First checks

```sh
curl -fsS http://127.0.0.1:8000/healthz
curl -fsS http://127.0.0.1:8000/readyz
suchi doctor
```

`/healthz` confirms the process is alive. `/readyz` also checks database and
schema readiness. `suchi doctor` reports the schema, filesystem, optional
tools, taxonomy, job health, and configured egress without exposing secrets.

Before storing important documents, configure TLS, create a complete backup,
and test a restore. Continue with [Mail intake](/guides/mail-intake),
[Configuration](/config), [Backup and restore](/backup-restore), or
[Importing from Paperless-ngx](/importer).
